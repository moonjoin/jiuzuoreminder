# jiuzuoreminder
久坐提醒，定时提醒你起来走走


## 项目简介

这是一款功能完善的桌面定时提醒应用程序，旨在帮助用户养成健康的工作习惯，定时休息，保护视力和身体健康。程序采用Python + Tkinter开发，界面简洁美观，功能丰富实用。

## 核心功能

### 🎯 智能提醒系统
- **灵活的时间设置**：支持自定义提醒间隔时间
- **快捷预设按钮**：30、45、60分钟三种常用时长一键设置
- **个性化提醒内容**：可自定义提醒文字内容
- **双重响应选项**：提供"我知道了"和"稍后提醒(5分钟)"两种处理方式

### 📊 数据统计分析
- **实时统计面板**：显示今日提醒次数、总提醒次数和累计运行时长
- **详细历史记录**：完整记录每次提醒的时间、内容和响应方式
- **数据导出功能**：支持将历史记录导出为CSV文件，便于进一步分析工作休息规律

### 🎨 现代化界面设计
- **响应式布局**：支持窗口大小调整，自适应不同屏幕
- **动态进度条**：实时显示倒计时进度，一目了然
- **美观的配色方案**：采用现代扁平化设计风格
- **友好的交互体验**：清晰的视觉反馈和操作提示

### ⚡ 性能优化
- **智能内存管理**：自动监控内存使用，定期执行垃圾回收
- **资源正确释放**：退出时自动清理所有线程和定时任务
- **长时间稳定运行**：优化设计确保程序可7x24小时稳定运行
